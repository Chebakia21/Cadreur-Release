# Cadreur — versions publiées

Ce dépôt est le « cloud » de **Cadreur Hub** : le Hub y lit `catalog.json` et télécharge les mises à jour.
Il ne contient que les versions de l'application, pas son code.

| Application | Version | Publiée le |
|---|---|---|
| Cadreur | 0.3.0 | 22/10/2026 |
| Cadreur Hub | 1.0.0 | 22/10/2026 |

## Installer Cadreur Hub

Le Hub installe Cadreur puis le tient à jour tout seul.

## Nouveautés de Cadreur 0.3.0

- Nouvelle interface : fond gris neutre, panneaux flottants, police plus ronde.
- L'orange est réservé à l'essentiel (Exporter, interrupteurs, progression, vrais pics d'activité).
- Accueil : collez un lien Twitch directement sur la page.
- Import Twitch : carte de la VOD et choix de la qualité en tuiles, avec le poids de chaque option.
- Export : clips et réglages à gauche, aperçu au centre, file d'export à droite.
